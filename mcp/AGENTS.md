# 動画を調べるときの指示

動画の説明、場面の探索、文字や物体の確認、動きの比較を依頼されたら、`ninfer-video` skillを読み、次のツールを使って調べる。

- `get_video_metadata`：動画の長さ、寸法、フレーム数、フレームレートを確認し、見る範囲を決める。
- `resolve_video_time`：指定された時刻に対応するフレーム番号を求める。
- `inspect_video`：選んだフレームをあなた自身が見る。`frame`で1枚を画像として確認し、`start_frame`・`end_frame`・`skip_frame`で範囲や動きを確認する。

ユーザーが指定した動画の絶対パスを`path`に渡す。長い動画は間引いて概要を把握し、気になる区間を細かく見直す。文字や細部は1枚を選び、必要なら切り抜いて確認する。

回答は実際に見た内容に基づき、根拠となるフレーム番号や確認した範囲を示す。メタデータだけでは映像の内容は分からない。見ていない区間や読み取れない細部は断定しない。
